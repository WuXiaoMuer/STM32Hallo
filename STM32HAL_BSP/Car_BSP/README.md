# 电机与舵机控制驱动库

该驱动库基于 STM32 硬件平台开发，提供了直流电机正反转 / 停止控制、舵机角度精准控制的底层接口，适用于智能小车、机械臂等嵌入式控制场景。

## 功能特性

1. **电机控制**：支持左右两路电机独立速度控制（含正反转）、紧急停止
2. **舵机控制**：支持两路舵机 0~180° 角度精准设置，超出范围自动限位
3. **硬件适配**：基于 TIM4 PWM 输出、GPIOB 引脚电平控制实现硬件驱动

## 硬件资源映射

表格

|    功能    |     硬件资源     |            说明             |
| :--------: | :--------------: | :-------------------------: |
| 右电机 PWM | TIM4 CH3（CCR3） |  速度值范围：-19999~19999   |
| 右电机方向 | GPIOB_PIN_12/13  | 低电平 / 高电平对应不同转向 |
| 左电机 PWM | TIM4 CH4（CCR4） |  速度值范围：-19999~19999   |
| 左电机方向 | GPIOB_PIN_14/15  | 低电平 / 高电平对应不同转向 |
|   舵机 1   | TIM4 CH3（CCR3） |      角度范围：0~180°       |
|   舵机 2   | TIM4 CH4（CCR4） |      角度范围：0~180°       |

## 接口说明

### 1. 电机控制接口

#### `void motor(int16_t Lspeed, int16_t Rspeed)`

- 功能：设置左右电机速度与转向

- 参数：

  - `Lspeed`：左电机速度（正数 = 前进，负数 = 后退，绝对值 8500~19999）
  - `Rspeed`：右电机速度（正数 = 前进，负数 = 后退，绝对值 8500~19999）

  

- 示例：

  ```
  motor(15000, 15000); // 左右电机以15000速度前进
  motor(-10000, 10000); // 左电机后退，右电机前进（原地左转）
  ```

  

#### `void motor_stop(void)`

- 功能：停止所有电机运行，关闭 PWM 输出并复位方向引脚

- 示例：

  ```
  motor_stop(); // 紧急停止电机
  ```

  

### 2. 舵机控制接口

#### `void Servo1_Angle(int16_t angle)`

- 功能：设置 1 号舵机角度

- 参数：`angle`：目标角度（0~180°，超出范围自动修正）

- 示例：

  

  ```
  Servo1_Angle(90); // 1号舵机转到90°中位
  ```

  

#### `void Servo2_Angle(int16_t angle)`

- 功能：设置 2 号舵机角度

- 参数：`angle`：目标角度（0~180°，超出范围自动修正）

- 示例：

  

  ```
  Servo2_Angle(45); // 2号舵机转到45°
  ```

  

### 3. 全局变量

- `extern int16_t Servo1`：1 号舵机当前角度值
- `extern int16_t Servo2`：2 号舵机当前角度值

## 使用步骤

1. 引入头文件：

   

   ```
   #include "bsp.h"
   ```

   

2. 初始化硬件（需确保 TIM4 PWM、GPIOB 引脚已完成底层初始化）

3. 调用对应接口控制电机 / 舵机：

   

   ```
   // 示例：电机前进2秒后停止，舵机转到指定角度
   motor(12000, 12000);
   HAL_Delay(2000);
   motor_stop();
   Servo1_Angle(30);
   Servo2_Angle(150);
   ```

   

## 注意事项

1. 电机速度值需控制在 8500~19999（绝对值），低于 8500 可能导致电机无法启动
2. 舵机与电机共用 TIM4 通道，同一时刻仅能使用一种功能（需避免冲突）
3. 使用前需确保 HAL 库已正确初始化，且相关 GPIO/TIM 外设时钟已使能
4. 电机方向引脚为推挽输出模式，需确保硬件电路匹配（如接电机驱动模块）
