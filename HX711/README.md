# HX711 称重传感器驱动



## 一、驱动概述

### 1.1 功能特点

- 读取 HX711 芯片 24 位原始数据，并完成符号位转换
- 支持传感器零点校准（去皮）
- 基于校准参数自动计算实际重量（单位：g）
- 适配 STM32F1xx HAL 库，底层延时 / IO 操作可灵活替换

### 1.2 硬件适配

- **主控芯片**：STM32F1xx 系列（如 STM32F103C8T6）

- **传感器**：HX711 + 电阻应变式称重传感器

- IO 口定义

  - SCK：HX711 时钟引脚（输出）

  - DOUT：HX711 数据引脚（输入）

    > 注：IO 口具体映射需在`gpio.h`中定义（如`SCK_GPIO_Port`、`SCK_Pin`、`DOUT_GPIO_Port`、`DOUT_Pin`）

## 三、核心宏定义与参数

### 3.1 校准参数（hx711.h）

|     宏定义      |                         说明                          | 默认值 |
| :-------------: | :---------------------------------------------------: | :----: |
|  `CAL_WEIGHT`   |   校准用已知重量（单位：g），需根据实际校准砝码调整   | 100.0f |
| `CAL_RAW_VALUE` | 对应`CAL_WEIGHT`重量的 HX711 原始读数，需实际测量校准 |        |

### 3.2 IO 操作宏

|    宏定义     |          说明          |
| :-----------: | :--------------------: |
| `HX711_SCK_H` | 设置 SCK 引脚为高电平  |
| `HX711_SCK_L` | 设置 SCK 引脚为低电平  |
|  `HX711_DT`   | 读取 DOUT 引脚电平状态 |

## 四、核心函数说明

### 4.1 原始数据读取

#### 函数原型

```
unsigned long HX711_GetData(void);
```

#### 功能

读取 HX711 原始 24 位数据，完成符号位转换（将补码转换为实际有效值），返回无符号长整型原始值。

#### 注意事项

- 底层依赖`delay_us()`微秒延时函数，需确保延时精度（建议误差 < 1us）
- 返回值为 HX711 的原始计数，未扣除零点，需结合校准参数计算重量

### 4.2 零点校准（去皮）

#### 函数原型

```
void HX711_CalZero(void);
```

#### 功能

读取当前空载状态下的 HX711 原始值，赋值给全局变量`hx711_zero`，作为重量计算的零点基准（去皮）。

#### 使用场景

- 传感器上电后首次校准
- 更换称重平台 / 环境后重新校准
- 需在传感器空载（无重物）时调用

### 4.3 实际重量计算

#### 函数原型

```
float HX711_GetWeight(void);
```

#### 功能

基于零点校准值和校准参数，自动计算当前实际重量（单位：g），返回浮点型结果。

#### 计算逻辑

```
实际重量 = (当前原始值 - 零点值) × 校准重量 / (校准原始值 - 零点值)
```

#### 特殊处理

- 若计算结果为负数（如空载时的微小波动），自动置为 0.0f
- 结果保留浮点精度，可根据需求四舍五入

### 4.4 内部辅助函数

#### 函数原型

```
static uint32_t HX711_ReadRaw(void);
```

#### 功能

内部静态函数，封装 24 位原始数据读取逻辑，供`HX711_CalZero()`和`HX711_GetWeight()`调用，不对外暴露。

## 五、使用步骤

### 5.1 前期准备

1. 确保`gpio.h`中正确定义 SCK/DOUT 引脚（如`SCK_Pin = GPIO_PIN_0`，`SCK_GPIO_Port = GPIOA`）；

2. 实现`delay_us()`微秒延时函数（需适配 STM32F1xx，精度要求 1us）；

3. 在工程中添加

   hx711.h和hx711.c

   文件，并包含头文件：

   

   ```
   #include "hx711.h"
   ```

### 5.2 基础使用流程



```
// 1. 初始化（上电后）
HX711_CalZero();  // 空载校准（去皮），务必确保传感器无重物

// 2. 读取重量
float weight = HX711_GetWeight();  // 获取当前重量（单位：g）

// 3. 示例：LCD显示重量（保留5位小数）
// LCD_ShowFloatNum1(45, 80, weight, 6, BLUE, WHITE, 16);
```

### 5.3 校准参数标定

若默认校准参数（100g 对应 8515530）与实际不符，需重新标定：

1. **空载校准**：调用`HX711_CalZero()`，记录零点值`hx711_zero`；
2. **加载砝码**：在传感器上放置已知重量的砝码（如 100g）；
3. **读取原始值**：调用`HX711_GetData()`，记录此时的原始值（即`CAL_RAW_VALUE`）；
4. **修改宏定义**：在hx711.h中更新`CAL_WEIGHT`（砝码重量）和`CAL_RAW_VALUE`（对应原始值）。
